# Информатика для первокурсника
Цель: помочь первокурсникам разобраться в устройстве персонального компьютера.
Автор: Князева Полина
Тема: Устройство компьютера.

## Список файлов:
- `glossary.md` — основные компоненты ПК и их термины.
- `examples.md` — примеры расчетов характеристик ПК.
- `sources.md` — полезные ссылки по архитектуре ЭВМ.
- `questions.md` — вопросы для самопроверки.

## Как пользоваться справочником
1. Изучите термины в `glossary.md`.
2. Разберите примеры расчетов в `examples.md`.
3. Проверьте себя с помощью `questions.md`.
